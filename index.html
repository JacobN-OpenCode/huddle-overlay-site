What it does

  • Floats above everything. Always-on-top, no dock icon, no alt-tab entry. It never steals focus.
  • Follows one thread. Paste a Slack thread link once and it polls every 2 seconds.
  • Reads like Slack. Real display names, real avatars, timestamps, emoji left alone.
  • Gets out of the way. Click-through mode makes the window ignore the mouse so you can type underneath.
  • Nervous about screen shares? One toggle hides it from screen recording and capture.
  • Yours. Opacity, font size, message lifetime, position and size are all remembered.

How it works

1

Install it

Open the .dmg on macOS and drag it to Applications, or unzip the Windows build and run HuddleOverlay.exe.

2

Point it at a thread

Right-click a Slack message → Copy link, paste it into the overlay, press Watch.

3

Put it where you want

Drag the header to move it, drag the corner to resize. ⌘⌥H / Ctrl+Alt+H toggles click-through.

How it reads Slack

Your session, your permissions

The app signs in with your existing Slack session on the device. It can only see channels you're already in — nothing is escalated, nothing is shared.

It makes five read-only calls: auth.test, conversations.info, conversations.replies, conversations.history and users.info.

Nothing leaves your machine

There is no backend. No analytics, no telemetry, no account system. Messages are kept in memory and dropped after the lifetime you set.

On macOS settings live in ~/Library/Application Support/Huddle Overlay; on Windows in %APPDATA%\Huddle Overlay.

Questions

Do I have to create a Slack app?

No. There's no bot to install and no OAuth dance. The app reuses the Slack session that's already on your computer.

Can it see channels I'm not in?

No. It makes the same API calls your Slack client does, so the permissions are identical to what you already have.

Why does it ask for a token sometimes?

If it can't find an existing session it falls back to asking for one, which you can grab from Slack's web client. It's a one-time thing and stays on your machine.

Is there a Windows build?

Yes. It's the same app — Electron instead of native Cocoa — built for Windows 10 and 11. Grab the .zip and run the executable.

Why is it so small?

Because it does one thing. If you want music in huddles, that's HuddleFM.
